# Ітерація 001: Базовий список машин

## Мета ітерації

Показати на сторінці список усих книг, отріманний з бекенду. Без фільтрів , без форм, без редагування - тільки читання і відображення

## Що вже є

Нічого, це наша перша ітерація. index.html/styles.css/app.js порожні або не існують

## Що додаємо

- Шапку сторінки з назваю "Cars Catalog"
- Список або таблицю машин: model,seller_name,vin,body_type,engine_volume, price, rating,is_available,description, year,tags
  body_typ- один із: sedan, crossover ,hatchback,wagon, coupe,convertible,minivan,pickup,suv
  -Завантаження списку через GET/cars/(без параметрів)- одразу після завантаження сторінки.
  -Стан завантаження ("Завантаження... ")і стан порожнього списка ("Машин поки немає")ю

## Явно позамежамі цієї ітерації

-Кнопки "Додати", "Редагувати", "Видалити"- Не додавати
-Фільтри і пагінація не додавати
-окремій банер для помилок API - не потрібен, достатньо console.error за наяності мереживої помилки

## Критерій приймання

-[+]- при відкритті виконується GET/cars/ і список відображається. -[+] - кожна кніга показує усі поля, переліченні в розділі, "що додаємо" -[+] - порожній список бекенду показує повідомлення , а не порожню сторінку
