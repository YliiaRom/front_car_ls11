# Ітерація 002:-Фільтри і пагінація

## Мета ітерації

Дати змогу звужувати список авто з фільтрамі і гортати його сторінкамі, не ламаючі відображення в ітерації 001.

## Що вже є

-Панель фільтрів зверху списка : select "тип кузова":sedan, crossover ,hatchback,wagon, coupe,convertible,minivan,pickup,suv; select -is_available "Доступність" ("доступне", " не доступне"); input type-number -rating "мінімальний rating"; input seller_name "ім`я виробник";year input -namber "рік випуску автомобіля" Кнопка "Застосувати"

- Застасованні фільтри передаються як query-параметри в GET/cars/(body_type,year,seller_name,is_available,min_rating).
  -Пагінація знизу: кнопкі "Назад" "Далі", що змінюють offset, (limit фіксований -10) і перезавантащують список із тімі самімі фільтрами.

## Явно позамежамі цієї ітерації

-Формі створення/редагування не додавати
-видалення- не додавати
-Окремий банер для API помилок не потрібен

## Критерій приймання

-[+] Зміна будьякого фільтра і натіскання "Застосувати" оновлює список відповідно до обраних значень -[+] Кнопка "Далі" збільшує offset і довантажує наступну сторінку (якщо вона є), "Назад" -зменшує і не йде у мінус. -[+]-Список і далі показує ті самі поля що і в ітерації 001
